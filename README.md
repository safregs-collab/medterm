# 🩺 МедТермин

Мобильная медицинская игра в стиле Wordle: нужно угадать медицинский термин за ограниченное число попыток.

## Версия для GitHub Pages

Проект подготовлен как полностью статический сайт. Сервер, Node.js и база данных для запуска игры не требуются.

### Структура

- `index.html` — приложение;
- `data/medical_terms.js` — словарь терминов;
- `manifest.webmanifest` — описание приложения для установки на главный экран;
- `.nojekyll` — отключает обработку Jekyll для статических файлов;
- `.github/workflows/deploy-pages.yml` — автоматическая публикация на GitHub Pages.

## Публикация

1. Создайте на GitHub новый репозиторий, например `medterm`.
2. Загрузите в него **содержимое этого архива**, а не сам ZIP.
3. Убедитесь, что `index.html` находится в корне репозитория.
4. Откройте `Settings → Pages`.
5. В `Build and deployment → Source` выберите `GitHub Actions`.
6. Сделайте push в ветку `main` или запустите workflow вручную во вкладке `Actions`.
7. После успешного workflow GitHub покажет опубликованный адрес сайта.

Для проектного сайта стандартный адрес имеет вид:
`https://ВАШ-АККАУНТ.github.io/medterm/`

## Возможности

- «Слово дня»;
- классический режим;
- режим по определению;
- режим с подсказками;
- термины разной длины;
- мобильная экранная клавиатура;
- физическая клавиатура на компьютере;
- перенос правильно найденных зелёных букв;
- локальная статистика;
- история партий;
- адаптивное окно настроек и справки;
- ежедневный пул ограничен терминами не длиннее 9 букв и сложностью не выше средней.

## Локальный запуск

Можно просто открыть `index.html` в современном браузере. Внешние зависимости отсутствуют.

## Медицинские данные

Словарь содержит учебные термины. Перед использованием в образовательном продукте с медицинскими утверждениями определения, классификацию и источники следует отдельно медицински верифицировать.
